# Installed policy role worker

## Scope

Read the retained launch prompt. Execute only the file-backed CLI jobs in
this life's private policy queue with this launch's original sealed binding
and socket descriptors. Retain exact requests, command bytes, mutation keys,
stdout, stderr and real process exits. A queue name grants no identity.

## Responsibilities

The L6 stages and applies sources through the public D6 operations. Each
change needs a fresh confirmation for its current generation and exact diff.
Other roles observe and evaluate only their own live context. Hook commands
are input data to the enforcing adapter; do not execute the sample commands.

## Deliverable

Retain the actual reserved session fields, authenticated identity, job bytes,
CLI observations and exits. Let the independent outside observer measure
native quiescence, archive read-back, workspace and branch collection.

## Must not

This is an explicitly declared credential-free executable fixture, with
simulated human presence and unproven physical approval. Make no model
request, login, paid-service selection or external delivery. Stop at the
first unexpected native refusal and retain its exact bytes. A successful
worker exit does not establish collection: wait for the outside observer to
retain the queues and release scratch, then leave the original worktree
clean for normal archive and native collection.
