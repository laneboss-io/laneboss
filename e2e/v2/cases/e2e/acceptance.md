Use the authorized disposable Ubuntu 24.04 box and the exact final installed
candidate/helper/vendor bytes. The active preparation, account/box requirements,
owner waits and producer handoffs are in ../ladder/READY.md.

Run the frozen --context FILE --result FILE entry only after source readiness,
two disjoint active installations, actual approved profiles/budgets, fresh L6

are ready. Missing requirements remain typed unreached failures.

seeded leaves contain two instances of each supported driver. The harness
starts only the two L6 roots; authentic parents start/review/archive/collect
children and report each descendant's independent planted answer upward.

causality, authentic requesters, parent end visibility within two seconds of
durable commit, sibling privacy, unchanged sources, complete primary/raw
capture, actual budgets/exits, independent zero-survivor measurements and
verified parent collection. Two complete trees must overlap at one common
instant with twenty actual kernel-pinned vendor executable identities.
One tree, sequential trees, stand-ins or model claims cannot pass.

The same candidate verifier rejects wrong token/path, foreign path, missing
ancestor answer, upward skip, early PONG, hidden/historical/fake end, first-mail
sender as actor, missing transcript/executable, surviving child and sequential
trees. A setup crash or exit 69 does not kill any product mutation.

events, and supplies actual parent receive timing, privacy canaries, kernel
brackets, source inventories and measured release/archive/collection receipts.

configuration-events or other required coverage stops before root dispatch.

Root tickets and operation-bound proofs remain outside prompts. Fresh hardware
ceremonies happen in person. Software presence remains simulated with
human_approval=not_proven; neither tests nor the harness manufacture approval.

Source ports and supporting case results are checked independently. Migration
planning and INTEGRATE-RECORDS cannot certify MIGRATE-ROLLBACK or
INTEGRATED-RELEASE. No installed/live ladder result or release acceptance is
inferred from harness units, real-store component tests or root canaries.
Independent reviews and real external machine collection remain required.
