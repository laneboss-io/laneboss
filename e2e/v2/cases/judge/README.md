# Judge wire, bounds and native recovery

The supervisor launches this installed entry on the authorized disposable
Ubuntu 24.04 machine after reviewing the tree and checks:

```sh
python3 -I -B scripts/v2-serve/run.py \
  --source /test/candidate \
  --evidence /test/evidence/lb-v2-case-judge \
  --item-case judge
```

The authoring lane runs unit/package checks through its authorized Linux
helper. Unit success is not an installed E2E result. On a fresh Ubuntu
box with Go, sudo and internet, run:

```sh
sh e2e/v2/cases/judge/BOX-SUITE.sh
```

The Linux isolation package runs on its own root-owned-binary box and is
excluded from importer runs here. It is not skipped inside a passing
suite. The native root canary uses the existing administrator kit and
real private namespaces, UID, cgroup, sealed descriptors and wait owner.

The producer is case_judge.py under scripts/v2-serve. It uses published
G0 boot/prepare/abort and dispatch before service teardown. Its measured
formatter executable and price bytes are installed before publication
hashes are calculated. The shared exporter hashes the complete source
archive and installed binary. Context/result use the frozen v2 schemas;
inputs and output evidence have separate private directories.

The declared Clef fixture uses Cloudflare/clef-flash, a loopback endpoint
and /v1/systemone. Its retained formatter specification counts
2 * complete_body_bytes + 32, with a 32-token safety margin. Context and
byte bounds are both 32,768, with twelve questions and a 2,000 ms total
command budget. The explicit price is one micro-unit per input or output
token, with a positive original reservation. This is fixture transport,
not live tokenizer or deployed-weight evidence. No credential is enrolled.

The producer launches a real service-issued L5 target. A private observer
uses the installed CLI and a fresh same-socket human session for each
preview/read. Copying a binding grants no transport authority. Consumer
inputs and actual CLI request bytes, stdout, stderr and exits are kept.
Independent collection checks native release, archive/read-back and
workspace removal. Unit shutdown supplies no case credit.

JUDGE-WIRE compares complete HTTP bytes, named command data, fixed
trusted questions, every Noul probability, model/deployment, usage, cost
and exact request read-back. The fixture derives answers from complete
body bytes and question ID. A constant score cannot pass. The approved
twelve-rule pack remains intact.

JUDGE-BOUNDS checks credential canaries, paired benign values, screen
caps, missing/duplicate/malformed answers, partial input, wrong model,
timeout, UTF-8 byte overflow and independent token overflow below the
byte cap. Missing/unavailable observations have no probability.
Screening precedes retention and acquisition: a later size refusal
cannot substitute for withholding. A timeout may return a typed
unavailable/deadline error while retaining its original cost reservation.
The consumer fabricates no reply from that failure.

JUDGE-AUDIT reads public egress records and blobs and checks hashes,
sizes, claim/attempt, reservation, outcome and provider request IDs.
Every observed send needs a retained pair. A timeout with no measured
outcome retains its positive reservation and unknown usage.

JUDGE-RECOVERY reuses exact input bytes, request ID and mutation key,
then independently observes actual service process replacement. Both
retries must return the original result with no additional HTTP request.
Store controls reopen real state and reject unknown, foreign, changed
or surviving outcomes while keeping their reservations. Those component
controls do not replace this public installed case.

The complete twelve-rule fixture is also measured in the native exchange
test. Its initial 16,384-token enrollment failed before HTTP because the
complete body required 17,490 fixture tokens; the declared 32,768-token
window admits that body and the independent token-overflow control.

The native red runner requires reached failures for the base CLI
handoff, base absent producer, removed native dispatch, removed native
gate, truncated provider relay and removed measured recovery. It restores exact bytes and reruns
each candidate. Build/setup failures cannot kill a control. Red inputs,
stdout/stderr/exits remain in its evidence directory; reached failure
lines and hashes enter the transcript. Ordinary unit runs never mutate
source; laneboss_judge_red selects that explicit isolated box phase.

TypeSafe's explicitly selected pinned contract has an input-driven HTTP
fixture in TestNativeWorkerExchange. The installed item selects Clef.
No live model request, login, hosted account, semantic calibration or
authenticated vendor acceptance is claimed. The separately owned fixed
corpus remains the calibration gate.
