## Fresh Room decisions

`Room` now uses the installed UsageJobs conversation for usage-enrolled
profiles. Every call launches or reconciles an actual usage job, authenticates
its original input/result frames, checks the exact acknowledgement, and retains
the raw command output before normalization. The common conversation moved
from `usage_source.go` into `usage_measurement.go`; limit-window parsing still
requires an exhausted from-profile window.

Room resolves the exact issued grant's current life, causing launch, protected
runtime and original service-origin quiescent end. The original from-profile
query measures provider-wide rows; the selected to-profile uses its own
protected vendor mapping. All selected windows must be below 100 percent.
Missing profiles, unknown or elapsed resets, duplicate rows, malformed values
and query failures stop the decision. None becomes initial availability or a
synthetic no-room receipt. Command observations must be post-exit and at most
30 seconds old. Room expires within one minute and within every grant,
enrollment and reset bound.

The normalized envelope is an immutable manifest readable by the target and
its exact supervising tree. The actual raw TSV remains service-private.
Encrypted `usage` journal records authenticate the original worker, grant,
profile enrollment and normalized bytes. Continuation authenticates both
committed observations, obtains another fresh measurement, and permits a new
receipt only while eligibility's subject and enrollment remain unchanged.
Acquisition carries that freshly measured room through protected preparation;
it no longer falls back to the initial room observation for this continuation.

Old limit provenance is metadata, never fresh availability or live worker
authority. Its original observation time authenticates the frozen envelope.
After a completed worker expires, the reader joins its original launch,
acknowledged lease, exact completed effect, actual result and measured exit.
Current profile, grant, run and cancellation fences still apply. The watchdog
can then request a separate fresh job after its backoff.
