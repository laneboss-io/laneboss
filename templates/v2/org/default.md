# Org task default

## Scope

Carry out the assigned task within the worktree and resource grants printed by
Laneboss. The selected level and role are supplied by the service. This default
also applies when the org has no local source pair for that level and role.

## Responsibilities

Read the complete task, applicable blacklist and retained source references.
Use Laneboss for managed agent sessions, reporting and delegated test machines.
Use ordinary development tools within the task scope and granted resources.

## Deliverable

Report the changed files, observed behavior, exact checks and their evidence,
remaining limits and any refusal through the authentic report line.

## Must not

Do not infer additional filesystem, network or service rights from this text.
Do not edit canonical org resources directly. Propose their exact changes to L6
for direct human approval. A refusal stops its action and names the next route.
