# Stopping an already ended run

An authorized `lane.stop` for the current uncleaned `verifying` or `accepted`
life with a committed quiescent run end completes idempotently. Its
`Operation.stop` contains the actual lane state, end event ID/sequence and
typed `RunEndEvent`, including the original exit code or signal. It records
no new stop/end event, effect, generation or cancellation epoch. The writer
independently derives the result from its protected current lane, launch
binding and end event under the same generation/epoch fences. Exact retry
returns the stored receipt. Never-started, abandoned, merged, cleaned, stale
and unverified-end controls retain their refusals. An ordinary live stop
continues to enqueue the existing stop effect and reports pending intent.

The rejected-vendor component executes pinned Claude Code 2.1.296 with the
real adapter's arguments, generated settings and each credential mode. Its
loopback provider rejects the synthetic credential with HTTP 401, and the
measured exit is retained before stop. The component maps the exact settings
namespace path to the actual private file; it does not execute the Claudock
wrapper or claim native helper isolation. It continues the same life through
quiescence, abandonment, verified archive bytes and fixture-owned collection.
A separate real SQLite receipt/journal check retains that measured exit code.
Full installed canary verification remains required. The installed harness
already accepts succeeded operations and checks actual quiescence, so its
assertions and execution path need no change.

For archive after a natural exit, terminal stop preserves the launch epoch
and abandonment or merge commits the next cancellation epoch. The native
owner still retains the original launch and release epochs. The archive
writer now revalidates the current job, requester, policy, grants, exact end,
generation and epoch, then privately hands off the committed terminal
decision. The helper pins that exact archive intent/epoch alongside its
immutable launch/release records before freeze. It requires the original
released process, withdrawn credentials/storage and measured quiescence;
freeze and every read-back retain exact epoch equality. No public RPC or
caller-selected epoch override is added. Cleanup retains the original fence
as evidence after the actual private roots are collected.

The rejected-vendor fixture now supplies its actual retained lifecycle records
to the production native epoch comparison. Its other native authority inputs
remain declared component data. A separate root canary measures real process
wait/cgroup/UID release, filesystem freeze/read-back, fence persistence and
private-root collection. A real SQLite archive reservation independently
exercises the committed writer handoff and refuses changed or stale fences.
